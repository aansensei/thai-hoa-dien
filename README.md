# Điện Thái Hòa

Bản xem điện Thái Hòa và sân Đại Triều bằng three.js, hậu cảnh SVG nhiều lớp.

Đây là bản đang phát triển. Hậu cảnh là minh họa. Hình học và chi tiết lịch sử còn cần đối chiếu; việc xuất bản không xác nhận tính chính xác lịch sử hoặc chất lượng hiển thị.
